What it does

A control room for every AI agent you already have.

🔎

Detect everything

Installed CLIs, local model runtimes, and desktop apps — with their skills, MCP servers, plugins, and configs.

🚀

Run headlessly

Delegate a task to one agent or fan out to many in parallel — no terminal babysitting.

🧪

Review locally

Every result is scored by a local model (Ollama) — private and $0 tokens.

🧠

Learn & route

Remembers what works and routes future work to the best tool — automatically.

🔗

Cross-tool chains

Pipelines where one step feeds the next — across different engines, in isolated git worktrees.

👁️

Live supervision

Observe and even interrupt a running Claude Code session via hooks.

♻️

Self-improving

Proposes better playbooks, A/B-tests them, and promotes only on a measured win — with auto-rollback & a kill switch.

🛡️

Safe by design

Fork-bomb guards, budgets, audit, loopback-only. Your configs and code never leave your machine.

How it works

A self-learning core with a pluggable body.

editors / external agents / running CLI sessions │ MCP (native .NET) · A2A + Zed ACP (TS sidecar) ▼ THE CORE / BRAIN memory · learning · routing · local review · governor ▼ Tool adapters one driver per CLI/runtime · cloud or local provider ▼ Orchestration spawn · supervise · git-worktree isolation · chains └── persistence (SQLite + transcripts) · append-only audit

Install & go

Per-user, no admin. Then wire it into your existing Claude Code sessions.

# Installer or portable from Releases, then:
armadillo doctor        # what's installed
armadillo run "..."     # run + review a task
armadillo chain "..."   # cross-tool pipeline
# Connect your existing Claude Code:
armadillo connect       # MCP + hooks
armadillo autostart on  # daemon at login
armadillo serve         # keep the brain up
